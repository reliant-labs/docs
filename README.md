# Reliant documentation has moved

**The live Reliant and Reliant Forge documentation is at
[docs.reliantlabs.io](https://docs.reliantlabs.io).**

This repository is an unused documentation template and does not hold the
current docs. Its content is not maintained, and nothing here is published at
docs.reliantlabs.io.

Where to go instead:

- **Documentation:** [docs.reliantlabs.io](https://docs.reliantlabs.io)
- **Search the docs from your agent** (a public, read-only MCP server, no
  account): `claude mcp add --transport http reliant-docs https://docs.reliantlabs.io/mcp`
- **Forge** (open source, Apache-2.0): [github.com/reliant-labs/forge](https://github.com/reliant-labs/forge)
- **Reliant:** [reliantlabs.io](https://reliantlabs.io)

To report a problem in the documentation, open an issue on
[reliant-labs/forge](https://github.com/reliant-labs/forge/issues) or use the
feedback link on any page of docs.reliantlabs.io.
